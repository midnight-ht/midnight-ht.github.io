Problem: ENOSPC System Limit for File Watchers Exceeded

When running npm or yarn projects on Linux, you may encounter the following error:

Error: ENOSPC: System limit for number of file watchers reached

Cause

The Linux system’s file watcher limit has been exceeded. The default limit is too low for projects with many files.

Check Current File Watcher Limit

cd /proc/sys/fs/inotify
ls
cat ./max_user_watches    # View current system user maximum limit

Solution

Temporary Fix (Lost After Reboot)

sudo sysctl fs.inotify.max_user_watches=524288
sudo sysctl -p

Permanent Fix

Edit /etc/sysctl.conf:

sudo nano /etc/sysctl.conf

Add or modify this line:

fs.inotify.max_user_watches=524288

Save and apply:

sudo sysctl -p

Verify the Fix

cat /proc/sys/fs/inotify/max_user_watches

You should see the updated value (524288 or higher).

Alternative for Development

If you don’t need file watching during development, you can disable it:

npm run build --no-watch
# or
yarn build --no-watch

Increase the value (524288) if you’re still experiencing issues with very large projects.
