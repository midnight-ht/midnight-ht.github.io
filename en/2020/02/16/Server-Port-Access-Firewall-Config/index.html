Solution: Server Port Access and Firewall Configuration

Problem After starting a new service on your server, public internet users cannot access it.

Problem

After starting a new service on your server, public internet users cannot access it. This is usually due to improper security group and firewall configuration.

Two-Step Solution

  1. Configure Alibaba Cloud Security Group
  2. Configure Linux Firewall

Step 1: Configure Alibaba Cloud Security Group

Prerequisites

  1. Log in to Alibaba Cloud Console
  2. Click the menu icon in the top left
  3. Select “Elastic Compute Service (ECS)”

Configuration Steps

1. Select Your Instance

Navigate to the instances list and click on your instance.

2. Select Security Group

In the instance details, click on the “Security Groups” tab.

3. Configure Security Group Rules

Click “Configure Rules” to manage inbound/outbound rules.

4. Add Security Group Rule

Click “Add Security Group Rule” button.

5. Fill in Rule Details

Configure the following:

Protocol: TCP (for most web services)
Port Range: 8080/8080  (or your specific port)
Authorization Object: 0.0.0.0/0  (allow all IP addresses)

Port Range Syntax:

  • 8080/8080 - Open only port 8080
  • 80/8080 - Open ports 80 to 8080 (range)
  • 8000/9000 - Open ports 8000 to 9000 (range)

Authorization Object:

  • 0.0.0.0/0 - Allow all IPs (public access)
  • 192.168.1.1/32 - Allow specific IP only
  • 10.0.0.0/8 - Allow specific IP range

Step 2: Configure Linux Firewall

1. Check Current Open Ports

sudo firewall-cmd --list-ports

Note: If you see “FirewallD is not running”, the firewall is disabled. You can either enable it or just rely on security group configuration.

2. Start Firewall Service

sudo systemctl start firewalld.service

3. Open Port

# Open a specific port permanently
sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent

# Replace 8080 with your actual port number

Command explanation:

  • --zone=public - Apply to public zone
  • --add-port=8080/tcp - Add port 8080 for TCP
  • --permanent - Make changes persistent across reboots

4. Reload Firewall

sudo systemctl restart firewalld.service

Or use:

sudo firewall-cmd --reload

Verification

Test if Port is Open

From Your Computer

# Test connectivity to server port
telnet your.server.ip 8080

# Or using curl
curl -v http://your.server.ip:8080

From the Server

# Check if service is listening
sudo netstat -tlnp | grep 8080

# Or using ss
sudo ss -tlnp | grep 8080

Common Issues and Solutions

Issue: Still Can’t Connect

  1. Verify security group rule is applied

    # In Alibaba Cloud console, check security group rules

  2. Check if service is actually running

    sudo systemctl status service-name
sudo ps aux | grep service-name

  3. Check firewall status

    sudo firewall-cmd --state

  4. Check iptables rules

    sudo iptables -L -n

Issue: Firewall Status Unknown

Check if firewalld is running:

sudo systemctl status firewalld.service

Enable and start firewall:

sudo systemctl enable firewalld.service
sudo systemctl start firewalld.service

Complete Checklist

  • Log in to Alibaba Cloud console
  • Select your instance
  • Go to Security Group tab
  • Add inbound rule for your port
  • Set authorization object to 0.0.0.0/0
  • Save the rule
  • SSH into your server
  • Check if firewall is running
  • Add port to firewall (if enabled)
  • Restart firewall
  • Test connectivity from external IP

Quick Reference

Common Service Ports

Service Port Protocol
HTTP 80 TCP
HTTPS 443 TCP
SSH 22 TCP
MySQL 3306 TCP
MongoDB 27017 TCP
Redis 6379 TCP
Node.js 3000, 8080 TCP
Nginx 80, 443 TCP

Firewall Commands

# Open port
sudo firewall-cmd --zone=public --add-port=PORT/tcp --permanent

# Close port
sudo firewall-cmd --zone=public --remove-port=PORT/tcp --permanent

# Reload firewall
sudo firewall-cmd --reload

# List all open ports
sudo firewall-cmd --zone=public --list-ports

# List all rules
sudo firewall-cmd --list-all
