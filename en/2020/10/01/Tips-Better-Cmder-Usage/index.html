Tips: Better Cmder Usage

What is Cmder? Cmder is a portable console emulator for Windows that provides a better command-line experience than the default Command Prompt.

What is Cmder?

Cmder is a portable console emulator for Windows that provides a better command-line experience than the default Command Prompt. It’s based on ConEmu and includes Git integration.

Installation

Method 1: Download Pre-built Version

  1. Visit cmder.net
  2. Choose version:
    • Mini (~2MB) - Core with Git
    • Full (~170MB) - Includes msysgit
  3. Extract to desired location
  4. Run Cmder.exe

Method 2: Using Chocolatey

choco install cmder

Basic Configuration

Add to Path

Make Cmder accessible from anywhere:

  1. Press Win + Pause to open System Properties
  2. Click “Advanced system settings”
  3. Click “Environment Variables”
  4. Add Cmder path to PATH (e.g., C:\Program Files\cmder)
  5. Restart Cmder or system

Set as Default Terminal

  1. Open Cmder as Administrator
  2. Go to Settings (Win + Alt + P)
  3. Startup > Run specific program
  4. Set your preferred shell

Useful Features

Split Panes

Ctrl + Shift + Alt + D     # Split pane horizontally
Ctrl + Alt + D             # Split pane vertically
Ctrl + W                   # Close active pane
Alt + Arrow Keys           # Switch between panes

Tab Management

Ctrl + T                   # New tab
Ctrl + Shift + T           # New tab (restores previous tabs)
Ctrl + Alt + Up/Down       # Move tabs
Ctrl + W                   # Close current tab

Window Management

Ctrl + Alt + Enter         # Toggle fullscreen
Alt + Enter                # Toggle maximized
Win + Alt + P              # Open settings

Text Selection & Copy

Shift + Arrow Keys         # Select text
Shift + Home/End           # Select to line start/end
Ctrl + Shift + C           # Copy
Ctrl + Shift + V           # Paste
Ctrl + L                   # Clear screen

Customization

Appearance Settings

  1. Open Settings: Win + Alt + P
  2. Navigate to Appearance
  3. Customize:
    • Font - Consolas (recommended)
    • Font Size - 14px for comfortable reading
    • Theme - Choose color scheme
    • Transparency - Set to preference

Recommended Theme Settings

Font: Consolas or FiraCode
Size: 14-16px
Color Scheme: Solarized or Monokai
Transparency: 10-20%

Shell Selection

  1. Settings → Startup
  2. Choose shell:
    • cmd.exe - Default Command Prompt
    • powershell.exe - PowerShell
    • bash - Git Bash (if Full version)

Aliases & Custom Commands

Create Command Aliases

Create file: %CMDER_ROOT%\config\aliases

Example:

# alias[=command]
gst=git status
glog=git log --oneline --graph --all
gcc=git commit -m
gp=git push
gl=git pull
e.=explorer .
cdnpm=cd C:\Users\YourUsername\AppData\Roaming\npm

Usage

gst                        # Runs: git status
glog                       # Runs: git log --oneline --graph --all
gcc "Initial commit"       # Runs: git commit -m "Initial commit"

Integration Tips

Visual Studio Code Integration

Add to VSCode settings.json:

"terminal.integrated.shell.windows": "C:\\Program Files\\cmder\\vendor\\conemu-maximus5\\conemu.exe",
"terminal.integrated.shellArgs.windows": [
    "/START",
    "cmd.exe",
    "/c",
    "cd %USERPROFILE%\\AppData\\Local\\Programs\\cmder\\bin && cmd"
]

Git Integration

Cmder comes with Git by default (Full version). Configure:

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

Advanced Features

Autocomplete

Start typing and press:

Ctrl + Shift + Space       # Show autocomplete suggestions

Command History

F1                         # Show command history
F3                         # Find in history

Task Scheduler

Create custom startup tasks:

  1. Settings → Startup → Tasks
  2. Add new task:
    • Name: “Python”
    • Command: cmd /k python
    • Icons: Set custom icon

Performance Tips

  1. Disable Aero - Improves rendering
  2. Reduce logging - Use Settings → Logging
  3. Update regularly - Download latest version
  4. Clean cache - Delete %CMDER_ROOT%\config\history

Keyboard Shortcuts Summary

Shortcut Action
Win + Alt + P Settings
Ctrl + T New tab
Ctrl + W Close tab
Ctrl + Shift + Alt + D Split horizontal
Ctrl + Alt + D Split vertical
Ctrl + Alt + Enter Toggle fullscreen
Ctrl + L Clear screen
Ctrl + Shift + C Copy
Ctrl + Shift + V Paste

Troubleshooting

Git Commands Not Found

  1. Reinstall Git for Windows
  2. Use Full version of Cmder
  3. Add Git to PATH manually

Slow Performance

  1. Disable transparency
  2. Reduce font size
  3. Update to latest Cmder version
  4. Check antivirus settings

Encoding Issues

Set UTF-8:

chcp 65001

Or add to profile file.

Comparison with Alternatives

Tool Pros Cons
Cmder Git built-in, customizable Windows only
PowerShell Modern, powerful Steeper learning curve
Windows Terminal Modern UI, lightweight Newer, less mature
Git Bash Git tools, familiar Limited Windows integration

Best Practices

  • ✅ Use aliases for frequently used commands
  • ✅ Customize colors for readability
  • ✅ Keep Cmder updated
  • ✅ Use split panes for parallel tasks
  • ✅ Configure appropriate shell for your needs
  • ❌ Don’t run untrusted scripts
  • ❌ Avoid modifying system folders

Start using Cmder to make your Windows terminal experience more productive!
