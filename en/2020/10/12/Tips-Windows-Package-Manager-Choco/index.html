Tips: Windows Package Manager - Chocolatey

What is Chocolatey? Chocolatey is a package manager for Windows, similar to on Linux or on macOS. It simplifies software installation and management.

What is Chocolatey?

Chocolatey is a package manager for Windows, similar to apt on Linux or brew on macOS. It simplifies software installation and management.

Installation

Method 1: Using PowerShell (Recommended)

Open PowerShell as Administrator and run:

Set-ExecutionPolicy AllSigned -Force
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

Method 2: Using Command Prompt

Run Command Prompt as Administrator:

@"%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -InputFormat None -ExecutionPolicy Bypass -Command "[System.Net.ServicePointManager]::SecurityProtocol = 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))" && SET "PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin"

Verify Installation

choco --version

Common Commands

Install Software

# Install a package
choco install python
choco install git
choco install nodejs
choco install vscode

# Install multiple packages
choco install python git nodejs -y

# Install specific version
choco install python --version=3.9.0

Manage Packages

# List installed packages
choco list

# Search for packages
choco search keyword

# Upgrade package
choco upgrade package-name

# Upgrade all packages
choco upgrade all

# Uninstall package
choco uninstall package-name

Advanced Usage

Create Custom Package

# Init new package
choco new package-name

# Pack package
choco pack

# Push to Chocolatey repository
choco push package-name.nupkg --key="YOUR_API_KEY"

Pin Package Version

Prevent automatic upgrades:

choco pin add --name=package-name --version=1.0.0
choco pin list
choco pin remove --name=package-name

Configuration

Edit Configuration

choco config list
choco config set name=value

# Examples
choco config set cacheLocation=C:\chocolatey\cache
choco config set containsLongRunningService=true

Tips & Tricks

Run Commands Without Confirmation

choco install package-name -y
# or
choco install package-name --yes

Install from Local File

choco install .\package-name.nupkg -s .

Use Proxy

choco install package-name --proxy=http://proxy.server:port

Update Chocolatey Itself

choco upgrade chocolatey

Troubleshooting

Command Not Found

Restart PowerShell or Command Prompt after installation.

Permission Denied

Run as Administrator:

# PowerShell
Start-Process powershell -Verb runAs

# Command Prompt
Right-click > Run as Administrator

Installation Fails

Try updating Chocolatey first:

choco upgrade chocolatey

Alternatives

  • Scoop - User-level package manager
  • Windows Package Manager (winget) - Microsoft’s official package manager
  • Winget - CLI package manager

  • ✅ Works from command line
