Solution: Docker Container Network Connectivity in Dockerfile

Problem When building Docker images with Dockerfile

Problem

When building Docker images with Dockerfile, the container cannot download dependencies because:

  • Container has no internet access
  • DNS resolution fails inside container
  • Network connectivity issues during build

Error Messages

Failed to resolve 'archive.ubuntu.com'
Unable to fetch package
Network error
Connection timeout

Root Causes

  1. Docker daemon DNS not configured - Missing DNS settings
  2. Host nameserver not accessible - Incorrect DNS in container
  3. Network routing issues - Host network configuration problem

Solution: Configure DNS for Docker

Method 1: Check Host DNS (Diagnostic Step)

# View host nameservers
cat /etc/resolv.conf

# Output should show:
# nameserver 8.8.8.8
# nameserver 8.8.4.4

Method 2: Restart NetworkManager (If Needed)

systemctl restart NetworkManager

Method 3: Configure Docker DNS Permanently

Step 1: Edit Docker Configuration

Create or edit /etc/default/docker:

sudo nano /etc/default/docker

Step 2: Add DNS Configuration

Add this line:

DOCKER_OPTS="--dns 8.8.8.8 --dns 8.8.4.4"

Recommended DNS Servers:

  • Google DNS: 8.8.8.8, 8.8.4.4
  • CloudFlare DNS: 1.1.1.1, 1.0.0.1
  • Quad9 DNS: 9.9.9.9, 149.112.112.112

Step 3: Restart Docker Service

sudo systemctl restart docker

Method 4: Alternative - Edit daemon.json

Edit /etc/docker/daemon.json:

sudo nano /etc/docker/daemon.json

Add DNS configuration:

{
  "dns": ["8.8.8.8", "8.8.4.4"]
}

Restart Docker:

sudo systemctl restart docker

Testing the Solution

Test During Build

# Try building with network access
docker build -t test-image .

# Or run a test container
docker run --rm ubuntu:20.04 apt-get update

Test Container Connectivity

# Check DNS resolution
docker run --rm busybox nslookup google.com

# Test internet connectivity
docker run --rm busybox ping -c 1 8.8.8.8

# Test package download
docker run --rm ubuntu:20.04 apt-get update

Updated Dockerfile

Good Practice - Install and Clean

FROM ubuntu:20.04

# Update package list and install
RUN apt-get update && \
    apt-get install -y \
        curl \
        wget \
        git \
        node.js \
    && rm -rf /var/lib/apt/lists/*

# Your application code
COPY . /app
WORKDIR /app

With Explicit DNS

FROM ubuntu:20.04

# Set DNS if needed (though not recommended in Dockerfile)
RUN echo "nameserver 8.8.8.8" > /etc/resolv.conf && \
    apt-get update && \
    apt-get install -y curl

Multi-stage Build (Recommended)

# Build stage
FROM ubuntu:20.04 as builder

RUN apt-get update && \
    apt-get install -y build-essential

WORKDIR /build
COPY . .
RUN make build

# Final stage
FROM ubuntu:20.04

RUN apt-get update && \
    apt-get install -y runtime-dependencies && \
    rm -rf /var/lib/apt/lists/*

COPY --from=builder /build/output /app
CMD ["./app"]

Docker Compose Configuration

version: "3.8"

services:
  app:
    image: ubuntu:20.04
    command: /bin/bash -c "apt-get update && apt-get install -y curl"
    dns:
      - 8.8.8.8
      - 8.8.4.4
    networks:
      - mynet

networks:
  mynet:
    driver: bridge

Debugging Steps

1. Check Docker Daemon Configuration

docker info | grep -i dns

2. Inspect Container DNS

# Run container and check DNS
docker run --rm busybox cat /etc/resolv.conf

# Should show:
# nameserver 8.8.8.8
# nameserver 8.8.4.4

3. Check Build Logs

docker build --verbose -t test-image .

4. Test Network from Container

docker run --rm ubuntu:20.04 bash -c \
  "apt-get update && echo 'Success'"

Complete Solution Checklist

  • Check host DNS: cat /etc/resolv.conf
  • Verify NetworkManager: systemctl status NetworkManager
  • Edit Docker configuration
  • Add DNS to DOCKER_OPTS or daemon.json
  • Restart Docker: systemctl restart docker
  • Test with: docker run --rm ubuntu:20.04 apt-get update
  • Verify in container: docker run --rm busybox cat /etc/resolv.conf

Quick Reference Commands

# View current Docker DNS
docker info | grep -A5 "DNS:"

# Restart Docker service
sudo systemctl restart docker

# Check if Docker is running
sudo systemctl status docker

# View Docker logs
sudo journalctl -u docker -n 50

# Rebuild image without cache
docker build --no-cache -t image:tag .

Troubleshooting Matrix

Problem Check Solution
apt-get fails DNS resolution Add DNS to docker config
Build hangs Network timeout Check firewall rules
Connection refused Service not running Restart Docker
Permission denied User permissions Run with sudo or add to docker group
DNS not working Container DNS Verify /etc/docker/daemon.json

Prevention

  1. Always test locally before deploying
  2. Use FROM official images - They usually have DNS pre-configured
  3. Cache layers - Use .dockerignore and layer caching
  4. Document DNS setup - Add comments to docker-compose.yml
  5. Monitor builds - Check build logs for network issues
