Clean Commits with Git Rebase

Cleanliness is an attitude. Avoid creating unnecessary commits. Learning to use the command will make you love Git all the more.

Cleanliness is an attitude. Avoid creating unnecessary commits. Learning to use the git rebase command will make you love Git all the more.

Merge Latest Two Commits

git rebase -i HEAD~2

To merge multiple commits, change the number according to how many commits you want to merge.

Auto-Enter Vi Edit Mode

pick e0b28b9 test 1
pick 670239a test 2

# Rebase 4195fd7..670239a onto 4195fd7 (2 commands)
#
# Commands:
# p, pick <commit> = use commit
# r, reword <commit> = use commit, but edit the commit message
# e, edit <commit> = use commit, but stop for amending
# s, squash <commit> = use commit, but meld into previous commit
# f, fixup <commit> = like "squash", but discard this commit's log message
# x, exec <command> = run command (the rest of the line) using shell
# b, break = stop here (continue rebase later with 'git rebase --continue')
# d, drop <commit> = remove commit
# l, label <label> = label current HEAD with a name
# t, reset <label> = reset HEAD to a label
# m, merge [-C <commit> | -c <commit>] <label> [# <oneline>]
# .       create a merge commit using the original merge commit's
# .       message (or the oneline, if no original merge commit was
# .       specified). Use -c <commit> to reword the commit message.
#
# These lines can be re-ordered; they are executed from top to bottom.
#
# If you remove a line here THAT COMMIT WILL BE LOST.
#
# However, if you remove everything, the rebase will be aborted.

Enter Edit Mode by Typing ‘i’, Change ‘pick’ to ‘s’ for All Lines Except the First

pick e0b28b9 test 1
s 670239a test 2

Complete the Rebase

  • Press Esc to exit edit mode
  • Type :wq to save and exit
  • Git will combine the commits and potentially open another editor for the combined commit message
  • After confirming the commit message, the rebase is complete

Useful Git Rebase Commands

Reword Commit Message

git rebase -i HEAD~3
# Change 'pick' to 'r' for the commit you want to edit

Delete a Commit

git rebase -i HEAD~3
# Change the line to 'd' or just delete the line

Edit a Commit

git rebase -i HEAD~3
# Change 'pick' to 'e' to stop at that commit
# Make your changes
# git add .
# git rebase --continue

Abort Rebase

If you make mistakes during rebase:

git rebase --abort

Best Practices

  1. Never rebase public commits - Only rebase commits that haven’t been pushed to a shared repository
  2. Keep history clean - Regularly squash related commits into logical chunks
  3. Use meaningful commit messages - After squashing, write clear combined commit messages
  4. Create backup branches - Before attempting complex rebases, create a backup branch
