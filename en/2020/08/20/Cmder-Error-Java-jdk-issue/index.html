Error Message

Error Cause

Environment variable configuration error caused by incorrect automatic configuration during JDK installation.

Solution

  1. Find the Error

  2. Correct it to the proper path

Steps to Fix

  1. Open System Environment Variables
  2. Look for any environment variables with incorrect JDK paths containing spaces or backslashes
  3. Edit or remove the problematic variables
  4. Restart Cmder or your command prompt
  5. Verify the fix by running java -version
