Installing Node.js on Linux and Setting Up Symlinks

This guide covers installing Node.js on Linux and configuring it to be globally accessible.

Article

This guide covers installing Node.js on Linux and configuring it to be globally accessible.

Step 1: Download Linux Version of Node.js

Visit the official Node.js website and download the appropriate version for your system.

Download Options

  • Long Term Support (LTS) - Stable, recommended for production
  • Current Release - Latest features
  • Previous Versions - Access historical versions

Recommended format: Linux Binary (x64)

Download Methods

Method A: FTP Upload

  1. Download on Windows
  2. Upload to Linux server using FTP tools like XFTP
  3. Offers free educational license

Method B: Direct Download with wget

wget https://nodejs.org/dist/v14.8.0/node-v14.8.0-linux-x64.tar.gz

Step 2: Move to Installation Directory

Copy to /usr/local (common installation directory):

cp ./node-v14.8.0-linux-x64.tar.gz /usr/local

Step 3: Extract and Rename

cd /usr/local
tar -zxvf node-v14.8.0-linux-x64.tar.gz  # Extract
ls                                        # List extracted files
mv node-v14.8.0-linux-x64 node            # Rename to 'node'

Step 4: Configure Global Variables

Option A: Using Symbolic Links (Per-Tool)

Create symlinks for each global dependency:

Set Node Symlink

ln -s /usr/local/node/bin/node /usr/local/bin/

Set npm Symlink

ln -s /usr/local/node/bin/npm /usr/local/bin/

Option B: Global Configuration (Recommended)

Edit the system profile:

sudo vi /etc/profile

Press i to enter edit mode, then add:

export NODE_HOME=/usr/local/node
export PATH=$NODE_HOME/bin:$PATH

Save and exit: Press Esc, then type :wq

Reload the profile:

source /etc/profile

Step 5: Verify Installation

node --version
npm --version

Enjoy Using Node.js

You can now use Node.js and npm globally on your Linux system!

Useful npm Commands

npm install -g <package>   # Install global package
npm install                 # Install local dependencies
npm start                   # Run project
