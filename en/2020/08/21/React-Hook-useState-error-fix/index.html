React Hook: useState Error Fix

Error Message

React Hook "useState" is called in function "xxx(函数名)" which is neither a React function component nor a custom React Hook function.

Problem Explanation

This error occurs when you violate the Rules of Hooks, specifically trying to use React Hooks in:

  • Regular JavaScript functions
  • Class components
  • Non-React functions

Causes

  1. Function is not a React component - Regular functions can’t use Hooks
  2. Function name doesn’t follow conventions - React uses naming to identify components
  3. Importing wrong component - Using a regular function instead of a component function
  4. Order of function definitions - Function defined before React imports

Solutions

✅ Correct Usage: Functional Component

import React, { useState } from "react";

// Correct: Component function name starts with uppercase
function MyComponent() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default MyComponent;

✅ Correct Usage: Custom Hook

import { useState } from "react";

// Correct: Custom hook function name starts with 'use'
function useCustomCounter() {
  const [count, setCount] = useState(0);

  return {
    count,
    increment: () => setCount(count + 1),
    decrement: () => setCount(count - 1),
  };
}

export default useCustomCounter;

❌ Incorrect: Using useState in Regular Function

import React, { useState } from "react";

// WRONG: Regular function (lowercase)
function helper() {
  const [count, setState] = useState(0); // Error!
  return count;
}

❌ Incorrect: Using useState in Class Component

import React, { useState } from "react";

// WRONG: Class component can't use Hooks
class MyComponent extends React.Component {
  componentDidMount() {
    const [count, setCount] = useState(0); // Error!
  }

  render() {
    return <div>Class Component</div>;
  }
}

Rules of Hooks

  1. Only call Hooks at the top level - Don’t call Hooks inside loops, conditions, or nested functions
  2. Only call Hooks from React functions - Call from functional components or custom Hooks
  3. Use the ESLint plugin - Install eslint-plugin-react-hooks

Common Mistakes and Fixes

Mistake 1: Calling Hooks Conditionally

// ❌ WRONG
function MyComponent() {
  if (someCondition) {
    const [state, setState] = useState(0); // Error!
  }
}

// ✅ CORRECT
function MyComponent() {
  const [state, setState] = useState(0);

  if (someCondition) {
    // Use the state
  }
}

Mistake 2: Calling Hooks in Event Handlers

// ❌ WRONG
function MyComponent() {
  const handleClick = () => {
    const [state, setState] = useState(0); // Error!
  };
}

// ✅ CORRECT
function MyComponent() {
  const [state, setState] = useState(0);

  const handleClick = () => {
    // Use the state
  };
}

Mistake 3: Wrong Function Export

// ❌ WRONG
const myHelper = () => {
  const [state, setState] = useState(0); // Error!
};

// ✅ CORRECT
const MyComponent = () => {
  const [state, setState] = useState(0);
  return <div>{state}</div>;
};

Installation & Setup

Install ESLint Plugin (Recommended)

npm install --save-dev eslint-plugin-react-hooks

Update .eslintrc

{
  "plugins": ["react-hooks"],
  "rules": {
    "react-hooks/rules-of-hooks": "error",
    "react-hooks/exhaustive-deps": "warn"
  }
}

Summary

  • ✅ Use Hooks only in functional components
  • ✅ Use Hooks only in custom hooks (functions starting with use)
  • ✅ Ensure component names start with uppercase letter
  • ✅ Use ESLint plugin to catch errors early
  • ❌ Don’t use Hooks in regular functions
  • ❌ Don’t use Hooks in class components
  • ❌ Don’t call Hooks conditionally
