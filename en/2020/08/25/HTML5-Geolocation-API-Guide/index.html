W3C Reference Standard

W3C Recommendation 8 November 2016 (GitHub reference added 31 January 2018)

Sources of Location Information

According to the W3C Geolocation API standard, the interface is independent of the underlying source of location information. Common sources include:

  • Global Positioning System (GPS) - Satellite-based positioning
  • IP Address - Network-based location inference
  • WiFi - SSID and MAC address-based positioning
  • Bluetooth - MAC address-based positioning
  • Radio signals - GSM/CDMA cell tower identification
  • User Input - Manual location specification

Note: The API does not guarantee the actual location of the device. The specification does not mandate the order of using these technologies.

Mobile Device Prioritization

Mobile devices with GPS prioritize satellite positioning. Laptops and tablets typically use WiFi for best accuracy. Desktop computers with wired internet can only use IP-based location, which has the lowest accuracy.

Security & Privacy Requirements

For privacy protection, the standard requires:

  • User Authorization - Must request and receive user permission
  • HTTPS Protocol - Required for all addresses except localhost and 127.0.0.1

Geolocation API Details

1. Environment Detection

Geolocation is a browser interface, so we must check if the browser supports it:

if ("geolocation" in navigator) {
  // Browser supports geolocation
} else {
  // Browser does not support geolocation
}

2. Built-in Methods

geolocation.getCurrentPosition()

Retrieves the device’s current position (one-time).

Parameters:

navigator.geolocation.getCurrentPosition(
  successCallback, // Required
  errorCallback, // Optional
  options, // Optional
);

Options Parameter:

{
    enableHighAccuracy: Boolean,  // Default: false
    timeout: Number,              // Milliseconds
    maximumAge: Number            // Cache duration in milliseconds
}

Example:

if ("geolocation" in navigator) {
  const successCallback = (position) => {
    console.log("Location obtained:", position);
  };

  const errorCallback = (error) => {
    switch (error.code) {
      case error.TIMEOUT:
        console.log("Geolocation request timed out!");
        break;
      case error.POSITION_UNAVAILABLE:
        console.log("Internal error! Unable to retrieve geolocation!");
        break;
      case error.PERMISSION_DENIED:
        console.log("Permission denied for geolocation!");
        break;
      default:
        console.log("Geolocation error:", error);
        break;
    }
  };

  const options = {
    enableHighAccuracy: true,
    timeout: 5000,
    maximumAge: 3000,
  };

  navigator.geolocation.getCurrentPosition(
    successCallback,
    errorCallback,
    options,
  );
} else {
  // Browser does not support geolocation
}

geolocation.watchPosition()

Continuously monitors the device’s position (returns a watch ID).

Parameters: Same as getCurrentPosition()

Example:

const watchId = navigator.geolocation.watchPosition(
  successCallback,
  errorCallback,
  options,
);

geolocation.clearWatch()

Stops monitoring the device’s position.

Parameters:

navigator.geolocation.clearWatch(watchId);

Example:

const watchId = navigator.geolocation.watchPosition(
  successCallback,
  errorCallback,
  options,
);

// Stop watching after 1 minute
setTimeout(() => {
  navigator.geolocation.clearWatch(watchId);
}, 60000);

3. Callback Response Format

Success Callback Response

{
    "coords": {
        "latitude": Number,          // Decimal latitude
        "longitude": Number,         // Decimal longitude
        "altitude": Number || null,  // Height in meters (WGS84 ellipsoid)
        "accuracy": Number,          // Precision in meters (non-negative)
        "altitudeAccuracy": Number || null,  // Height precision in meters
        "heading": Number || null,   // Direction in degrees (0-360)
        "speed": Number || null      // Speed in m/s (non-negative)
    },
    "timestamp": Number              // Unix timestamp
}

Error Response

error.code; // Error code (PERMISSION_DENIED, POSITION_UNAVAILABLE, TIMEOUT)
error.message; // Error description

Complete Example

function getLocationAndWatch() {
  if (!("geolocation" in navigator)) {
    console.error("Geolocation not supported");
    return;
  }

  // Get current position
  navigator.geolocation.getCurrentPosition(
    (position) => {
      const { latitude, longitude, accuracy } = position.coords;
      console.log(
        `Current location: ${latitude}, ${longitude} (±${accuracy}m)`,
      );
    },
    (error) => {
      console.error(`Geolocation error: ${error.message}`);
    },
    {
      enableHighAccuracy: true,
      timeout: 10000,
      maximumAge: 300000,
    },
  );

  // Watch position changes
  const watchId = navigator.geolocation.watchPosition(
    (position) => {
      console.log("Position updated:", position.coords);
    },
    (error) => {
      console.error("Watch error:", error);
    },
    {
      enableHighAccuracy: true,
      timeout: 5000,
      maximumAge: 0,
    },
  );

  // Stop watching after 10 minutes
  setTimeout(() => {
    navigator.geolocation.clearWatch(watchId);
    console.log("Position tracking stopped");
  }, 600000);
}

getLocationAndWatch();

Best Practices

  1. Always check browser support before using the API
  2. Handle errors gracefully - Users may deny permission
  3. Use appropriate options - Balance accuracy with battery life
  4. Provide user feedback - Show loading state during position retrieval
  5. Cache results - Avoid excessive API calls
  6. Use HTTPS - Required for security (except localhost)
