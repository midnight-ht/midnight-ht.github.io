Tips: Accelerate GitHub Downloads

Problem GitHub downloads can be slow, especially when: Cloning large repositories Downloading releases Working from regions with limited connectivity

M Midnight Engineering notes on development, quality, security, delivery, and operations. View Author Profile
Updated 2020-11-20 · Estimated read 8 min
Translations
zh-CN en

Article

Problem

GitHub downloads can be slow, especially when:

  • Cloning large repositories
  • Downloading releases
  • Working from regions with limited connectivity

Solution 1: Use Official GitHub Mirror Services

Using Ghproxy (Recommended)

Ghproxy is a free GitHub mirror service:

# Original URL
git clone https://github.com/username/repository.git

# Using Ghproxy - Add ghproxy.com/https:// prefix
git clone https://ghproxy.com/https://github.com/username/repository.git

Download Release Files:

# Original
https://github.com/username/repository/releases/download/v1.0/file.zip

# Via Ghproxy
https://ghproxy.com/https://github.com/username/repository/releases/download/v1.0/file.zip

Using FastGit

Another popular mirror service:

# Clone with FastGit
git clone https://hub.fastgit.xyz/username/repository.git

# Also supports raw content
# Raw: https://raw.fastgit.xyz/username/repo/main/file.js

Using Gitclone

# Clone with Gitclone
git clone https://gitclone.com/github.com/username/repository.git

Solution 2: Configure Git SSH

SSH can be faster and more stable:

# Generate SSH key
ssh-keygen -t rsa -C "your_email@example.com"

# Add to GitHub account (Settings > SSH and GPG keys)
# Copy content of ~/.ssh/id_rsa.pub

# Clone using SSH
git clone git@github.com:username/repository.git

Solution 3: Partial Clone (Shallow Clone)

For large repositories, only clone recent history:

# Clone only last 1 commit (much faster)
git clone --depth=1 https://github.com/username/repository.git

# Clone with last 5 commits
git clone --depth=5 https://github.com/username/repository.git

# Clone specific branch only
git clone --depth=1 --branch main https://github.com/username/repository.git

# Clone specific branch, specific tag
git clone --depth=1 --single-branch https://github.com/username/repository.git

Solution 4: Use Proxy/VPN

If you have a proxy server:

# Configure git proxy
git config --global http.proxy http://proxy.server:port
git config --global https.proxy https://proxy.server:port

# Unset proxy if needed
git config --global --unset http.proxy
git config --global --unset https.proxy

Solution 5: Increase Git Buffer Size

# For large files
git config --global http.postBuffer 524288000

# Check current value
git config --global http.postBuffer

Solution 6: Download Releases Directly

Instead of cloning large repos:

# List releases
curl -s https://api.github.com/repos/username/repo/releases | grep download_url

# Download specific release
wget https://github.com/username/repo/releases/download/v1.0/file.zip

Speed Comparison

Method Speed Pros Cons
Direct Clone Slow Simple Subject to network issues
Ghproxy Fast Stable, free Third-party dependency
SSH Medium Secure, stable Setup required
Shallow Clone Fast Quick initial clone Limited history
FastGit Fast Reliable Third-party service

Recommended Configuration

Add to your .gitconfig:

[http]
    postBuffer = 524288000
    compression = 0

[core]
    compression = -1

Or use command:

git config --global http.compression -1
git config --global core.compression 0

Troubleshooting

Still Slow?

  1. Check network speed: speedtest-cli
  2. Check DNS: nslookup github.com
  3. Try different mirror service
  4. Use VPN to different region
  5. Clone at off-peak hours

Clone Fails?

  1. Increase timeout:

    git config --global http.lowSpeedLimit 0
git config --global http.lowSpeedTime 999999

  2. Resume clone:

    git config --global http.postBuffer 1g

Best Practices

  • ✅ Use shallow clone for large repos: --depth=1
  • ✅ Use SSH for frequent cloning
  • ✅ Use mirror services for once-off downloads
  • ✅ Configure compression settings
  • ✅ Clone during off-peak hours when possible
  • ❌ Don’t clone entire history if not needed

Related Tools

  • Gitpod - Cloud-based development
  • GitHub Desktop - GUI client with optimizations
