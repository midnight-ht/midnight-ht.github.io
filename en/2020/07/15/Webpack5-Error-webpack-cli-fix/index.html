Error Message

Error: Cannot find module 'webpack-cli/bin/config-yargs'

Common Scenarios

This error typically occurs when:

  1. Installing webpack5 for the first time
  2. Upgrading from webpack4 to webpack5
  3. Running webpack commands with incompatible webpack-cli versions

Root Causes

  1. Version mismatch - webpack-cli not updated to webpack5 compatible version
  2. Incomplete installation - webpack-cli dependencies not fully installed
  3. Corrupted node_modules - Cache or corruption in dependencies

Solutions

Solution 1: Update webpack-cli (Recommended)

npm install --save-dev webpack-cli@latest

Or specify a compatible version:

npm install --save-dev webpack-cli@4

Solution 2: Clean Install

# Remove dependencies
rm -rf node_modules package-lock.json

# Reinstall
npm install

# Or use yarn
yarn install

Solution 3: Manual Fix

# Uninstall webpack-cli
npm uninstall webpack-cli

# Reinstall the latest version
npm install --save-dev webpack-cli

Solution 4: Update package.json Scripts

Ensure your build scripts use the correct webpack command:

{
  "scripts": {
    "build": "webpack",
    "dev": "webpack serve --mode development",
    "prod": "webpack --mode production"
  }
}

Webpack5 Breaking Changes

Webpack5 introduced several breaking changes:

  1. Node.js version requirement - Minimum Node.js 10.13.0
  2. Module federation - New feature for code sharing
  3. Automatic asset type - No need for file-loader/url-loader
  4. Cache improvement - Built-in persistent caching

Updated webpack.config.js Example

module.exports = {
  mode: "production",
  entry: "./src/index.js",
  output: {
    path: __dirname + "/dist",
    filename: "bundle.js",
  },
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: {
          loader: "babel-loader",
        },
      },
      {
        test: /\.(png|jpg|gif)$/,
        type: "asset", // Webpack5 native asset handling
      },
    ],
  },
};

Verification

After applying the fix, verify with:

webpack --version
webpack-cli --version
webpack build --help

You should see versions without errors.

Prevention

  1. Keep dependencies updated regularly
  2. Use compatible versions - Check package versions
  3. Use npm ci - For reproducible installs in CI/CD
  4. Lock versions - Use package-lock.json or yarn.lock
