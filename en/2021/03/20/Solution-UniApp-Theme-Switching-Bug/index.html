Solution: UniApp Theme Switching - Flash/Flicker Bug Fix

Problem Description

In UniApp non-nvue mode (web-view rendering), switching themes causes:

  • Screen flashing (白屏 - white flash)
  • Screen flickering (闪屏 - black flash)
  • Status bar theme color instability
  • Inconsistent theme application across page navigation

Root Cause Analysis

When UniApp compiles for App in non-nvue mode:

  1. The __uniappview.html entry file loads first
  2. It reads the default theme configuration from manifest.json
  3. When loading different pages, it reloads the entry file again
  4. Between file loading and page rendering, the theme color flashes to default

The solution addresses this by caching theme selection and pre-loading styles early.

Solution Steps

Step 1: Cache Theme Selection in App

Add this code in your theme-switching function (button click handler):

// Cache theme selection using HTML5+ API
plus.storage.setItem("theme", this.color);

Best practice: Place this in the business page component where theme switching occurs.

Step 2: Create __uniappview.html

File Location

Create __uniappview.html in the assets directory (create if doesn’t exist)

Reference Source

  • Original: GitHub - uni-app

Complete File Content

<!DOCTYPE html>
<html lang="en-US">
  <head>
    <meta charset="UTF-8" />
    <script>
      var __UniViewStartTime__ = Date.now();
      var coverSupport =
        "CSS" in window &&
        typeof CSS.supports === "function" &&
        (CSS.supports("top: env(a)") || CSS.supports("top: constant(a)"));
      document.write(
        '<meta name="viewport" content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0' +
          (coverSupport ? ", viewport-fit=cover" : "") +
          '" />',
      );
    </script>
    <title>View</title>

    <script type="text/javascript">
      function PlusReady() {
        // Singleton pattern
        if (typeof PlusReady.instance === "object") {
          return PlusReady.instance;
        }

        // Get cached theme from app storage
        this.color = plus.storage.getItem("theme");
        this.cssPath = "";

        // Style element for root styles (prevents flashing)
        this.style = document.createElement("style");
        this.link = document.createElement("link");

        // Track if DOM has been updated
        this.domStatus = false;

        /**
         * Set theme based on color value
         * Initialize theme colors, CSS path, and root styles
         */
        this.setTheme = function () {
          if (this.color == "black") {
            // Dark theme
            plus.navigator.setStatusBarStyle("light");
            this.cssPath = "static/css/black.css";
            this.style.innerText = `
                            body, html, #app, page {
                                background: #1E1E1E !important;
                            }
                        `;
          } else {
            // Light theme (default)
            plus.navigator.setStatusBarStyle("dark");
            this.cssPath = "static/css/white.css";
            this.style.innerText = `
                            body, html, #app, page {
                                background: #FFFFFF !important;
                            }
                        `;
          }

          // Initialize link element
          this.link.type = "text/css";
          this.link.rel = "stylesheet";
          this.link.href = this.cssPath;
        };

        /**
         * Inject styles into document head
         * Prevents flashing during page transitions
         */
        this.pushHead = function () {
          document.head.appendChild(this.link);
          document.head.appendChild(this.style);
        };

        return (PlusReady.instance = this);
      }

      /**
       * Called when plus (HTML5+) is ready
       */
      function plusReadyTheme(str) {
        let plusReady = new PlusReady();
        plusReady.color = plus.storage.getItem("theme");
        plusReady.setTheme();
      }

      // Initialize theme immediately if plus is already loaded
      if (window.plus) {
        let plusReady = new PlusReady();
        plusReady.setTheme();
        plusReady.pushHead();
      } else {
        // Wait for plusready event if plus not yet loaded
        document.addEventListener(
          "plusready",
          function () {
            let plusReady = new PlusReady();
            plusReady.setTheme();
            if (!plusReady.domStatus) {
              plusReady.pushHead();
            }
          },
          false,
        );
      }
    </script>
    <link rel="stylesheet" href="view.css" />
  </head>

  <body>
    <div id="app"></div>
    <script src="__uniappes6.js"></script>
    <script src="view.umd.min.js"></script>
    <script src="app-view.js"></script>
  </body>
</html>

Step 3: Install Copy Webpack Plugin

# Install copy-webpack-plugin (version 5.0.0+)
npm install --save-dev copy-webpack-plugin

Step 4: Create vue.config.js

Create vue.config.js in project root to copy __uniappview.html during build:

const path = require("path");
const CopyWebpackPlugin = require("copy-webpack-plugin");

module.exports = {
  configureWebpack: {
    plugins: [
      new CopyWebpackPlugin([
        {
          from: path.join(__dirname, "assets"),
          // Copy assets directory (contains __uniappview.html)
          force: true, // Force overwrite existing files
        },
      ]),
    ],
  },
};

Status Bar Color Instability Solution

Problem

Page renders correctly, but then performs self-navigation (jump to same page), causing:

  • Page doesn’t reload
  • Configuration reloads
  • UniApp shell reverts status bar to default theme

Solution

Only navigate if the target page is NOT already in the page stack:

// Before navigation
const pages = getCurrentPages();
const targetPath = "/pages/index/index";

// Check if page already exists in stack
const pageExists = pages.some((page) => page.$page.path === targetPath);

// Only navigate if page doesn't exist
if (!pageExists) {
  uni.navigateTo({
    url: targetPath,
  });
}

Better Approach - Use replaceAll

// Use replaceAll instead of navigateTo for theme switch
uni.reLaunch({
  url: "/pages/index/index",
});

Implementation Example

Vue Component - Theme Switcher

<template>
  <view>
    <button @click="switchTheme('black')">Dark Theme</button>
    <button @click="switchTheme('white')">Light Theme</button>
  </view>
</template>

<script>
export default {
  data() {
    return {
      currentTheme: "white",
    };
  },
  methods: {
    switchTheme(theme) {
      // Cache theme selection
      plus.storage.setItem("theme", theme);
      this.currentTheme = theme;

      // Apply CSS variables
      document.documentElement.setAttribute("data-theme", theme);

      // Refresh page stack to apply theme
      const pages = getCurrentPages();
      if (pages.length > 0) {
        uni.reLaunch({
          url: pages[pages.length - 1].$page.route,
        });
      }
    },
  },
};
</script>

Known Limitations

First page after theme switch: The first page navigated to after theme switch may still show a brief flash. This is a known limitation of the current approach.

Testing Checklist

  • Light theme CSS loads without flashing
  • Dark theme CSS loads without flashing
  • Status bar color matches theme
  • Theme persists after app restart
  • No white/black flash during navigation
  • Page content loads before theme assets finish downloading
  • Theme switches smoothly between pages

Alternative Solutions

Solution A: Use NVue Mode

For most stable theme switching, consider using NVue mode instead of web-view rendering.

Solution B: Service Worker Caching

Pre-cache theme CSS files using service worker for instant loading.

Solution C: System Theme Detection

// Detect system theme preference
const prefersDark = window.matchMedia("(prefers-color-scheme: dark)");
plus.storage.setItem("theme", prefersDark.matches ? "black" : "white");

Summary

This solution prevents theme-switching flash by:

  1. ✅ Caching theme selection in app storage
  2. ✅ Loading theme CSS early in entry file
  3. ✅ Pre-setting root element styles
  4. ✅ Setting status bar color synchronously
  5. ✅ Using webpack plugin to copy custom entry file

While not perfect, this approach significantly reduces flashing and improves user experience during theme transitions.
