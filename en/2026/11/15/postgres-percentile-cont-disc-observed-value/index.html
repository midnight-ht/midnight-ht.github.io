Why does a PostgreSQL median show a value absent from the data?

Use four observations to distinguish interpolation from observed-value selection in PostgreSQL.

M Midnight Engineering notes on development, quality, security, delivery, and operations. View Author Profile
Updated 2026-11-15 · Estimated read 8 min
Translations
zh-CN en

Article

Key takeaways

  • The continuous percentile can interpolate.
  • A discrete percentile selects an input value.
  • Check record identity separately from the statistic.

A PostgreSQL continuous percentile can return a value that never appeared in the input. Given 10, 20, 30, and 40, it interpolates a median of 25. The discrete aggregate selects an input value and returns 20 for the same fraction.

Suppose an import report shows a typical completion time, and a support tool wants to find a matching record. A result of 25 milliseconds need not match any record. Decide whether the field promises an estimate or an observed value before choosing the aggregate.

Identify the rule that produces the result

PostgreSQL 18 documents the continuous and discrete ordered-set aggregates separately. The continuous function can interpolate between adjacent values. The discrete function takes the first sorted input whose position reaches the requested fraction. For the four values here, 25 is midway between 20 and 30, while the second input reaches half the ordered set. PostgreSQL 18 aggregate functions.

The order inside WITHIN GROUP supplies the aggregate’s ordering. Sorting output rows serves a different purpose. These aggregates ignore SQL NULL inputs. If rows without a measurement still count as tasks, report the measured count separately from the total. The percentile gives those missing tasks no measured durations.

Check both results on four observations

This teaching query was not run. It includes four millisecond values and one SQL NULL. Each expected output is independent.

WITH samples(ms) AS (VALUES (10), (20), (30), (40), (NULL))
SELECT count(ms) AS measured,
       percentile_cont(0.5) WITHIN GROUP (ORDER BY ms) AS interpolated,
       percentile_disc(0.5) WITHIN GROUP (ORDER BY ms) AS selected
FROM samples;

Expect measured 4, interpolated 25, and selected 20. Save those expectations without calling the same function to generate them. If a display rounds its result, check the database value before presentation. A screen with no decimal digits cannot establish that the discrete aggregate was used.

A second control could contain 10, 20, 20, and 40. Both choices can return 20 at the median there. Keep the distinct middle values in the differentiating fixture. Test a group with no usable measurements separately, including whether the report should retain the group and what it should display for a missing percentile.

Choose a result the consumer can use

A capacity report can use a continuous estimate and label it as such. A threshold that must be one of the input tiers can use the discrete result. Neither supplies a stable record ID. If several tasks share the selected duration, define which task represents it and verify two equal values with different IDs.

Check the grouping and join input too. An accidental extra occurrence can change the distribution even with the intended aggregate. Save the contributing row identities and measured count before inspecting the result. The related PromQL histogram article concerns cumulative buckets; this example uses exact observations.

An alert threshold of 22 milliseconds would be crossed by the continuous median here and missed by the discrete median. Write down which statistic the alert uses, then test the database result, display, and alert state independently. This alert control was not run.

What if the fraction array contains NULL?

The array overload preserves the shape of its fraction input. With one-quarter, NULL, and three-quarters, expect continuous results 17.5, NULL, and 32.5, or discrete results 10, NULL, and 30. Preserve the middle position when assigning display labels. This array variation was not run, and the main example has no database execution receipt.
