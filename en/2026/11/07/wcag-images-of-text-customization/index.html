Does alt text satisfy WCAG requirements for images of text?

Check text, customization and essential-presentation conditions, including artwork alongside equivalent visible text.

M Midnight Engineering notes on development, quality, security, delivery, and operations. View Author Profile
Updated 2026-11-07 · Estimated read 13 min
Translations
zh-CN en

Article

Key takeaways

  • Alt alone does not establish visual customization.
  • Equivalent visible text and artwork can coexist under the stated conditions.
  • Classify screenshots and essential presentation individually.

Alt text alone does not establish WCAG1.4.5 compliance. Determine whether text should convey the information, the image is visually customizable, or its particular presentation is essential. A text alternative does not automatically turn visible pixels into text whose font, colors and spacing can be changed.

WCAG2.2 SC1.4.5 requires text rather than images of text when the technologies in use can achieve the presentation, subject to customizable and essential-presentation exceptions. This Level AA requirement does not remove every image from a website, and an alt field cannot certify an entire page.

Ask what needs adjustment

Imagine an event page containing only a poster. Its date, venue, eligibility and registration instructions are all rendered into the image. An accurate alternative may convey that content to someone using it, while another reader needs a dark background, different font or larger line spacing. Enlarging the whole poster does not independently change those characteristics.

The Understanding document describes customization of size, foreground and background, font, spacing and alignment. Separate an appropriate text alternative from adjustable visual information. Functional image alternatives addresses a different naming responsibility.

Receiving only an image from a designer does not establish essential presentation. The decorative typeface used for an event date is distinct from the date itself. A specimen demonstrating a particular typeface may depend on its precise appearance. Explain how changing that appearance would fundamentally change the information, rather than equating production convenience with necessity.

Give the poster and visible text explicit roles

The explanation expressly allows an image alongside text conveying the same information, with both presented to users. A constrained CMS can therefore retain the artwork and supply visible text. A heading and promotional sentence are insufficient if eligibility, cost or cancellation conditions remain only in the poster.

This complete static HTML has not been executed. The runner must supply poster.png; the example includes no image asset. Names, dates and places are fictional teaching data. There is no form, registration endpoint or persistence.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<title>Teaching event information</title>
<style>
body { max-width: 48rem; margin: auto; padding: 1rem; }
img { max-width: 100%; height: auto; }
.info { line-height: 1.6; font-size: 1rem; }
</style>
</head>
<body>
<h1>Evening reading discussion (teaching example)</h1>
<figure>
  <img src="poster.png" alt="Reading-discussion poster; full teaching details follow">
</figure>
<section class="info" aria-labelledby="details">
  <h2 id="details">Event information</h2>
  <dl>
    <dt>Time</dt><dd>November 20, 2026, 19:00–20:00</dd>
    <dt>Place</dt><dd>Teaching Library, second-floor discussion room</dd>
    <dt>Eligibility</dt><dd>Adults on the teaching list; participation is free</dd>
    <dt>Registration</dt><dd>This page takes no registrations; no real entry is provided</dd>
  </dl>
</section>
</body>
</html>

The alt text identifies the image and directs readers to the details; it is not a universal poster template. Important visual information absent from the text still needs appropriate treatment. Avoiding repetition is not a reason to give every image an empty alternative. Here, complete text appears on the same page rather than only in a separate download.

Compare each poster detail against the text: start and end times, floor, age requirements, price and capacity can change a decision. A new poster showing a different venue beside stale text creates conflicting information even if both are legible. The text needs maintenance as an authoritative presentation, not as an expendable summary.

A shared information source can feed artwork and text, or an existing CMS can assign an explicit text review when replacing the image. Shared data is a design choice that can reduce divergence, not a guarantee of correct rendering. Inspect the delivered page rather than merely checking that database fields exist.

Do we have to remove the poster image?

No. The explanation permits the image alongside visible text conveying the same information. Where the technology supports it, HTML and CSS can carry the main information while images serve meaningful illustration or branding. Choose according to content responsibilities, not one compulsory layout.

Customizable images are another listed condition. A zoom button alone does not establish user control over font, colors and background. If relying on customization, specify which characteristics can change, whether information remains complete and how readers find the controls. This article implements no such generator and verifies no exception through execution.

Must all text inside screenshots become HTML?

Not necessarily. The definition excludes text within images containing significant other visual information, including some screenshots, diagrams and graphs. Calling a rasterized notice a screenshot does not establish that condition. Assess what the image conveys beyond its text rather than deciding by filename.

Essential branding has its own limits. Logotype text is considered essential, and a font specimen can require a specific appearance. Neither condition automatically exempts adjacent dates, navigation or body text. A local exception must not silently expand to all page information.

Proposed checks compare image-plus-alt, image-plus-complete-visible-text and a version deliberately omitting an eligibility condition. Check information item by item, then change font, size, foreground/background and spacing while finding the time and deciding eligibility. Retain omissions, clipping and overlap rather than only a default screenshot.

Text-spacing overrides can test the resulting text layout but do not replace classification of content and exceptions. No browser, screen-reader or user study has been run here. First explain the chosen text, equivalent-visible-text or exception path; then inspect what readers can adjust and read.
