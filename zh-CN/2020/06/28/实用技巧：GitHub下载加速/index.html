例子：

git clone https://github.com/vuejs/vue.git

一、使用码云

  1. 登陆码云后，点击右上角加号
  2. 从GitHub/GitLab导入仓库
  3. 截取需要加速的GitHub仓库地址，点击导入
  4. 等待仓库生成…
  5. 使用生成仓库地址下载

二、使用代理

  git clone https://github.com.xxxxx/vuejs/vue.git // xxxxx 为代理地址
  • 推荐使用cnpmjs.org
    git clone https://github.com.cnpmjs.org/vuejs/vue.git
