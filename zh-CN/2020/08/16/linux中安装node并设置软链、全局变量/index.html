linux中安装node并设置软链、全局变量

正文

  1. 下载linux版本的node.js。

    在官网中点击tab中的下载。页面跳转后可看到有俩个子tab，长期支持版、当前发布版，可依据需求选择下载版本。选择下载其它历史版本的node，下拉页面可看到 以往的版本 按钮，点击后会跳转至历史版本页面，选择需要下载的版本，然后点击对应版本右方的下载按钮，选择对应的系统版本即可下载。linux较为常用的版本为 Linux 二进制文件 (x64) ，当然具体选择依据你的系统版本。

    • 在widows下访问node官网 下载，选择liunx版本。下载完成后使用FTP工具上传至安装目录。个人常用的FTP工具为XFTP，默认为收费的，但是官方提供了教育版免费开放，在教育版页面填入名字、邮件选择需要下载的软件后，邮箱会收到下载地址。
    • 使用linux中的wget命令下载。
      下载地址在找到需要下载的版本后，直接点击为下载，右键可以复制出下载地址，复制出来直接使用即可。
          wget https://nodejs.org/download/release/v14.8.0/node-v14.8.0-linux-x64.tar.gz
  2. 迁移至安装目录。

    常用的安装目录为 /usr/local 。

        copy ./node-v14.8.0-linux-x64.tar.gz /usr/local
  3. 解压文件并重命名。
        cd /usr/local
    tar -zxvf node-v14.8.0-linux-x64.tar.gz // 解压
    ls // 查看解压后的目录
    mv node-v14.8.0-linux-x64 node // 重命名
  4. 设置全局变量
    • 软链接
      缺点：每一个node的全局依赖都得单独设置。
      • 设置node软链
        ln -s /usr/local/node/bin/node /usr/local/bin/
      • 设置npm软链
        ln -s /usr/local/node/bin/npm /usr/local/bin/
    • 全局设置

      1. 打开配置文件

            vi /etc/profile

      2. 输入： i

        进入编辑状态

      3. 拉至文件尾部加入

            export NODE_HOME=/usr/local/node
    export PATH=$NODE_HOME/bin:$PATH

      4. ESC后输入：:wq
        保存并退出

      5. 重新加载profile文件

            source /etc/profile
  5. 愉快的使用node。
