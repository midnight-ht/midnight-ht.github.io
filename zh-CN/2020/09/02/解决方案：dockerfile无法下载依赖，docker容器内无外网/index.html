一、 查看宿主机的nameserver

    > cat /etc/resolv.conf
    options single-request-reopen
    nameserver 8.8.8.8
    nameserver 8.8.8.4
    $systemctl restart NetworkManager

二、 创建或修改 /etc/default/docker,在其中添加或编辑如下选项

    DOCKER_OPTS="--dns 8.8.8.8"

三、 重启 docker

    systemctl restart docker
