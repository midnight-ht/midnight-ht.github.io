每天看 p 值，显著就停：原来的 5% 承诺还在吗？

普通检验的单次门槛不能自动控制显著就停的全程错误率。用两观察时点的精确教学枚举，比较固定终点、序贯推断与安全停机的不同合同。

正文

核心要点

  • 先明确门槛控制单个时点还是整个停止策略。
  • 累计观察彼此相关，不能直接套独立检验公式。
  • 安全停机和控制错误率的收益结论分别记录。

看板每天都能打开，但按普通 p 值随时宣布胜出，需要另一份统计设计。一次时点的百分之五门槛，不自动约束整段观察中“有一次显著就停”的决定。改变停止方式以后，原先想控制的错误事件也变了。

这不要求团队停止观察伤害。问题在于把监控、安全行动和收益证明共用一个临时门槛，然后仍声称结果满足最初的固定终点承诺。Ham 等人的置信序列原始论文在第一点一节区分单个时点覆盖与全时间覆盖；这里依据版本标识 v3 和本次原文快照，不把页面额外显示的日期当成新的修订证明。

门槛究竟约束哪一种事件？

固定终点检验可以控制“在约定样本量下错误拒绝零假设”的概率。若每天重算并在任一天显著时结束，真正触发发布的是这些拒绝事件的并集。每一天单独合格，不等于并集仍有相同错误率。较早的偶然偏离可以触发停止，而本来后续会回落的数据再也不会进入决策。

各天累计数据彼此重叠，因此不能机械套用互相独立的多次检验公式，把天数代入就算出实际误报率。流量到达、指标延迟、停止规则和所用统计量都会影响结果。需要检查的是整个策略，而不是只确认某次 p 值函数算得对。

产品指标分母讨论过相同业务窗口的重要性，但这里还有额外条件：窗口不能在看到有利结果后随意缩短、看到不利结果后继续延长。先写一个期限，后来按照结果挑期限，也不再是那份预先约定的设计。

用四千零九十六条路径看清差别

下面是独立公平二元观察的教学模型，不是两组转化的生产分析。零假设规定每次得到零或一的概率各一半，十二次观察有四千零九十六条等可能路径。计划只在第十二次判断，采用双侧精确二项检验：取较小的含端点尾概率乘二，再与百分之五比较。

第十二次的拒绝区是成功数不超过二，或至少十。每侧路径数为一加十二加六十六，即七十九，两侧共一百五十八。固定终点的实际拒绝概率是一百五十八除以四千零九十六，约百分之三点八五七；离散检验不必恰好用满百分之五。

再增加第六次观察，任一次显著就停。第六次全零或全一即可拒绝，其中一些路径在第十二次已经不显著。以头六次全零为例，后六次出现三、四、五或六个一，分别有二十、十五、六和一条路径；对称方向一样，共额外八十四条。并集变成二百四十二条，概率约百分之五点九〇八。

下面完整脚本未作为本文发布示例执行，不提供运行截图或真实实验输出。文中的预期计数由上面组合数手算独立给出；整数比较避免把浮点门槛误差混入说明。

from itertools import product
from math import comb

def rejects(k, n):
    tail = sum(comb(n, j) for j in range(min(k, n-k) + 1))
    return 40 * tail <= 2 ** n

terminal = early_only = 0
for path in product((0, 1), repeat=12):
    at_end = rejects(sum(path), 12)
    terminal += at_end
    early_only += rejects(sum(path[:6]), 6) and not at_end
assert terminal == 158
assert early_only == 84
print({'all_paths': 4096, 'terminal': terminal,
       'any_look': terminal + early_only,
       'terminal_rate': terminal / 4096,
       'any_look_rate': (terminal + early_only) / 4096})

代码里的四十来自把“双倍尾概率不超过零点零五”移项为整数不等式。该模型只证明指定策略下的事件计数，不估算某家公司日看板的误报幅度，也不声称所有提前停止都会恰好得到这个百分比。它足以推翻一个更窄的承诺：重复使用相同单次门槛，并不自动保留整个实验至多百分之五的保证。

先选择停止合同，再配置胜出按钮

若工具只支持固定终点分析，可以先确定随机化单位、主指标、样本目标、业务时长和数据成熟要求。看板可继续显示运行情况，但胜出决定应遵循该计划。不能因为某一天恰好好看就宣布提前收工，也不能只为跨过门槛无限追加样本。

确实需要提前决策时，可选择预先安排观察节点和边界的组序贯设计，或满足相应假设的持续有效推断。原始论文用置信序列表达全时间覆盖，也区分精确与渐近构造。它不是把普通置信区间换个名字；实现还需确认分配方式、估计对象、依赖条件和有限样本承诺。

选择取决于团队必须在哪些时点行动，以及是否有能力审查和维护对应统计实现。固定期限并非总最省，持续监控也不是免费的统计能力。临时改指标、反复挑切片或把失败实验不记入报告，会再增加选择问题，不能认为选了一个序贯工具就全部解决。

发现严重伤害，必须等预定终点才能停吗？

不必。安全规则可以要求立即停止继续暴露，并保留停止原因、权限与当时数据。这个风险行动不需要伪装成另一个版本已被证明有收益。如果停止后仍要报告具有错误率承诺的效果结论，就需要与实际停止方式相容的推断，而不能继续引用未执行到底的旧合同。

发现阶段的停止条件也允许不再投入，但那是产品决策原则，不是序贯统计保证。区分两者以后，团队可以坦率地说“因伤害信号停止，收益尚未确认”，而不必在安全与诚实报告之间二选一。

验证时先复算一百五十八与额外八十四条路径，再用指定无效应模型检查完整停止策略。真实实验还要保留每次观察时间、样本成熟状态、指标版本及最终停止依据。只留最终那一张显著截图，已经无法让下一位评审者判断团队究竟执行了哪份合同。
