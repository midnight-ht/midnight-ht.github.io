WCAG 2.5.8：从命中区域到间距例外的检查法

目标尺寸要量实际热区和邻近目标；小目标可按间距例外判断，动态状态需要重查。

正文

核心要点

  • 24×24 CSS 像素针对有效指针目标，不能只量图标或外接框。
  • 小目标的 24 像素圆要同时避开其他目标及其他小目标的圆。
  • 等效、行内和必要性例外都要记录满足条件的具体证据。

工具栏里的删除图标用鼠标很容易点中，但这不足以判断它是否满足 WCAG 2.2 的目标尺寸要求。评审对象是指针真正能够激活的区域，以及它和邻近目标的几何关系。一个 16 像素的图形可以拥有较大的点击区；一枚看似宽大的圆角按钮，也可能因为有效区域的形状和邻居的位置而需要继续检查。

先把图案与目标分开

WCAG 2.2 成功准则 2.5.8 的 W3C 解释给出的最低尺寸是 24×24 CSS 像素，等级为 AA，并允许明确列出的例外。这条规则针对指针输入目标，不能直接拿设计稿中 SVG 的画板尺寸代替浏览器里的命中区域。按钮的内边距如果也能激活动作，就属于目标；外边距只制造视觉距离，通常不会自动变成可点击区域。背景色也不可靠：透明的按钮仍可能接受点击，画得很宽的图形也可能只有局部绑定了事件。

考虑一个假设的工具栏：可见删除图案为 16×16 CSS 像素，包裹它的按钮为 28×28。若按钮整个区域都响应相同删除动作，尺寸判断从按钮实际区域开始，而非图案。反过来，若事件只绑在图案上，视觉上有 28 像素的外框也不能证明目标足够。例子用于说明检查方法，尚未针对一个真实页面测量。评审时应在浏览器中标出命中边界，并从实际点击或元素事件关系核对空白区域是否可操作；只读 CSS 的 width、height 不能覆盖伪元素、裁剪、覆盖层和嵌套交互带来的差异。

尺寸也不是单看外接框两个数字。W3C 对异形目标的解释是：有效目标内部应能容纳一个与页面轴对齐、完整落在目标内的 24×24 CSS 像素实心正方形。极大圆角、斜切或镂空形状可能有足够宽的外接框，却放不进这个正方形。对普通矩形按钮，量宽高常常够用；对复杂 SVG 热区或裁剪目标，必须看实际形状。若目标被另一层盖住，开发者工具显示的元素盒子也不能代表用户可激活的部分。

小目标的间距例外怎么算

不足尺寸时，并非立即失败。间距例外要在每个小目标的外接框中心放一个直径 24 CSS 像素的圆。这个圆不能与其他目标相交，也不能与另一个小目标对应的圆相交。这里的“其他目标”既包括另一个小图标，也包括旁边很大的整卡链接。只检查横向两个图标之间的空白，是把二维条件误读成了一条水平间隔公式。

可用一个纸面布局推演：一排 20×20 的方形按钮，边与边相隔 4 CSS 像素，中心距离为 24。两个直径 24 的圆在边界相切而不相交，满足这个示例中的圆与圆关系；W3C 的示意也采用了这一排法。但不要把“加 4 像素”写进组件库当通用免检规则。若按钮在下一行、贴着一个可点击卡片，或因响应式换行而移动，新邻居可能落入圆内。目标不是方形时，圆仍从外接框中心计算，视觉重心不是判定点。设计交付里应记录视口、组件状态和所有相邻可点目标，让复核者知道圆究竟与谁比较。

比较两个修法也有实际取舍。扩大目标一般更直接，特别适合删除、提交等误触代价高的操作，但扩出的热区不能覆盖旁边按钮，否则一个位置对应两个动作。增加间距可保留视觉密度，却受换行和缩放后布局影响；仍要在各布局状态重新量。把大目标与小目标之间插入不可点的视觉留白，只有在圆确实不碰到大目标时才成立。仅把图案缩小并保持原布局，既不扩大目标也不保证例外。

例外要有对应的事实

同页等效控件例外要求另一控件完成相同功能且满足准则。如果小图标删除的是这条记录，页面另一处的“清空全部”不是等效操作。行内例外适用于句子中的目标，或目标尺寸受非目标文字行高限制；工具栏按钮旁写着文字，不会自动成为行内链接。用户代理控件例外看尺寸是否由浏览器决定且未经作者修改。必要性例外看特定呈现是否承载信息或受法律要求，例如地图点位的空间位置，而不是“界面比较挤”。这些不是可随意贴上的标签；团队应把所选例外和对应控件、句子或信息限制记在审查记录里。

动态内容也不能漏掉。菜单未展开时的图标与展开后菜单项是不同目标集合；弹窗、建议列表或浮层出现后，新出现的目标仍需检查。某个按钮暂时被交互结果遮挡时，W3C 解释说明该阶段有相应处理，但浮层里的操作目标并不因此获得豁免。评审截图应覆盖默认、展开、错误提示和窄屏等会改变邻接关系的状态。放大也不能直接当作满足 CSS 像素要求的证据，因为准则以 CSS 像素表述；放大后的重排是否保留功能，可另见放大与重排的检查。

一种可执行的交付记录是：对每个关键操作标出有效目标轮廓、尺寸或间距例外、最近邻居、查看时的视口与状态，并注明若使用其他例外其依据是什么。先用几何检查发现明显问题，再用键盘和真实指针操作观察误触、焦点与任务完成；后者帮助改进体验，却不能替代几何准则的判定。合规评估也有更广范围，单篇文章不能证明一页通过 WCAG。对这枚删除图标，只有把实际热区与邻居画出来，才能决定扩大按钮、调整布局，还是记录一个确实成立的例外。
