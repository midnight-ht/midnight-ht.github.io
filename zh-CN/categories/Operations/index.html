MySQL DDL 卡住时，前一条失败语句为什么还会挡路？

MySQL 8.4 中，语法有效但执行失败的语句可能仍把 metadata lock 持有到事务结束；autocommit 下则随语句结束释放。查 DDL 等待时要追踪事务和持锁连接，不只看最后一条 SQL。

PostgreSQL 18 事务超时，为什么会把连接一起结束？

PostgreSQL 18 的 transaction_timeout 限制的是一次事务占用会话的总时长，触发后会终止会话。理解它与语句超时、空闲事务超时的比较关系，再决定按角色或连接设置。

版本化 S3 对象 DELETE 返回成功，为什么旧文件还在？

启用版本控制的 S3 桶中，不带 versionId 的 DELETE 通常创建 delete marker，让对象表现为已删除；恢复要精确移除当前 marker，永久删除旧版本则是另一项操作。

SQS 心跳续租能减少抢重消息，但十二小时上限不会重置
